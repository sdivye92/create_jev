# A tag is "<what changes>_seed<N>" and is also the name of the result file in experiments/results/<group>/.
#   main_crossentropy  the standard recipe, trained with cross-entropy only
#   main_brier         the same recipe, with a Brier term added to the loss (--brier 1.0)

#   size100/200/400    only the first 100, 200 or 400 training records instead of 800
#   seed0 / seed1 / seed2   the random seed (--seed). Same settings with a different seed repeats the experiment with different random luck
